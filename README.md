# Let's Build · Rahul Gautam

A personal portfolio website for **Rahul Gautam**, a nature-inspired builder working across bamboo construction, natural materials, site-specific installations, festival spaces, and hands-on execution.

The portfolio brings together projects across architecture, installations, and festival spaces, with an emphasis on **making, materials, people, and the realities of building on site**.

## About the Project

The website is designed to feel closer to a visual archive than a conventional professional portfolio.

Rather than focusing only on finished photographs, it captures Rahul's role in the process: working with designers and artisans, prototyping, adapting materials, solving structural challenges, and taking ideas from drawings to physical spaces.

The content is based on Rahul's existing portfolio and project documentation.

## Project Categories

* Architecture
* Installations
* Festival Spaces

Selected projects include work across India and internationally, from bamboo structures in Darjeeling and Pune to installations in Mumbai and Jeddah, and large-scale festival spaces in Arunachal Pradesh.

## Design Direction

The website aims for a tactile, editorial feel that reflects Rahul's practice.

Key ideas:

* Natural materials and craftsmanship
* Strong visual storytelling
* Minimal, typography-led layouts
* Project details without unnecessary corporate language
* A sense of movement between projects
* Process and execution given as much importance as the final outcome

The central idea is simple:

> **Let's Build.**

## Project Structure

The site is organised around:

* **Home** — introduction and project discovery
* **Projects** — visual archive of Rahul's work
* **About** — Rahul's background, approach, and philosophy
* **Project details** — role, collaborators, location, materials, scale, and execution
* **Contact** — direct contact information
